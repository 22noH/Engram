# 다음 세션 인수인계 (2026-07-26 기준)

현재: `main` = `34081d2` · 앱/npm/플러그인 **v0.0.16**(2026-07-26 게시, `releases/latest`·npm 확인 완료)

## 릴리스하는 법 (한 줄)

```
git tag v0.0.16 && git push origin v0.0.16
```

태그 숫자가 곧 버전이다. CI가 `package.json`·`plugin.json`에 적용 → 3-OS 빌드 → npm 게시(OIDC, 토큰 불필요) → main에 버전 되돌림 커밋까지 자동.
게시만 재시도하려면: Actions → npm-publish → Run workflow → `version=0.0.16`.

**게시는 이제 자동이다**(v0.0.16에서 고침). `desktop-release.yml`이 `draft`(릴리스 하나 선점) → `build`(3-OS가 그 드래프트에 자산만 올림) → `publish`(세 OS 매니페스트 확인 후 `make_latest`로 게시) 순으로 돈다. 사람이 드래프트를 손으로 합칠 일도, `make_latest`를 챙길 일도 없다.
세 OS 중 하나라도 실패하면 `publish`가 아예 안 돌아 드래프트로 남는다(반쪽 릴리스 차단) — 실패한 OS만 재실행하면 이어서 게시된다.

## 1순위 — 미제 버그

### `code=1` 백엔드 크래시 (최우선)
- 며칠째 미제. 오늘 "LanceDB 패닉이 진범"이라 단정했다가 **반증으로 기각**: 패닉 수십 회를 안고 9.5시간 생존한 자식이 있고, 반대로 **패닉 0건인데 code=1로 죽은** 자식도 있다. RSS 1.4~1.8GB 증가도 패닉 유무와 무관.
- **다음 발생 시 갈리도록 계측을 심어뒀다**: `state/boot-progress.json`(마지막 단계) + `src/main.ts`의 `exit`/`beforeExit` 훅. 로그가 남으면 JS 경로, 안 남으면 네이티브 abort·OOM·외부 kill.
- 증거 위치: `%APPDATA%\Engram\logs\child-stderr.log`(자식 stdout/stderr+종료코드), `desktop-shell.log`(셸 판정). **로그 대괄호 시각은 UTC다** — 이거 놓쳐서 오늘 오진했다.

### "리슨은 하는데 로그가 0줄"
- 47800을 리슨하는데 pino 로그도 `state/heartbeat`도 한 줄도 안 남는 조합. 격리 환경에서 **재현 실패**, 원인 미상. 계측만 남김.

### RSS 1.4~1.8GB
- V8 힙은 ~280MB로 안정 → 네이티브(임베딩/RAG onnxruntime 추정). 미규명.
- ⚠️ `ENGRAM_HEAP_SNAPSHOT=1`을 켜지 마라 — 그 상태에서 동기 스냅샷이 OOM을 촉발한다.
